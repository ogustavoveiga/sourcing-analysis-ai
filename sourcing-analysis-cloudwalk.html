Approach

01
Funnel Conversion
Stage-by-stage drop-off analysis to locate the primary bottleneck. Measured both stage-to-stage and sourced-to-stage conversion simultaneously to capture compounding loss effects.
02
Channel Efficiency
Hire rate and no-response rate combined per channel. A channel with good hire rate but 40% ghost rate tells a different story than raw conversion alone.

Individual performance crossed with best-performing channel. The goal: is this a capability gap or a channel assignment problem?

Response time buckets, score averages, seniority, work mode, and department — identifying which attributes predict hire before the offer stage.
05
Rejection Patterns
Categorizing drop-off causes into engagement-driven, quality-driven, process-driven, and candidate-driven — to distinguish systemic from individual problems.

02 //

Use of AI

Live · Claude API

AI Candidate Scorer — Primary Differentiator

The dashboard's AI Scorer tab calls claude-sonnet-4-20250514 in real time. A recruiter inputs a candidate profile — channel, seniority, scores, response time — and Claude reasons against the actual dataset patterns to return: a hire probability (High / Medium / Low), a 0–100 confidence score, the top 3 contributing factors with positive/negative impact labels, a single actionable recruiter recommendation, and a persist / deprioritize flag with a one-sentence justification.

This is not a rule-based system. Every evaluation is grounded in the real dataset statistics injected into the prompt — hired candidate score averages, channel hire rates, response time benchmarks — making it a calibrated tool, not a generic AI opinion.

// AI as Analyst

All quantitative analysis was performed via structured Claude prompts — no Python scripts. 8 prompts total, each documented with exact wording and design rationale in the GitHub /prompts folder. Every prompt was designed for a specific output, not a general summary.

// AI as Insight Interpreter

A dedicated recommendation prompt required each output to include: the specific action, the data point that justifies it, the expected impact, and the responsible owner. This prevents generic advice — every recommendation is anchored to a real number.

04 //

Recommendations

01
Fix Outreach Quality Before Adding Volume
// Data: 210 no-response rejections = 56% of all rejections
Audit and rewrite outreach messages for LinkedIn (37% ghost rate), Hunting (36%), and Indicação (40%). Implement a 2-follow-up / 10-day rule: archive candidates who do not respond. Track no-response rate as a primary KPI alongside hire rate.
Expected: +30 active candidates/cycle from 15% response improvement
02
Realign Recruiters to Their Best Channels
// Data: Every recruiter converts 2× better in their best channel vs overall
Assign Fernanda → Hunting (8.3% vs 3.9%). Assign Diego → Hunting (11.8% vs 4.9%). Focus Gustavo → Github (14.3% vs 5.0%). Keep Bruno on Banco de Talentos (already his strongest channel at 28.6%).
Expected: Team hire rate from 8% → ~11% without new headcount
03
Fast-Track Medium-Response Candidates
// Data: 3–6 day responders convert at 15.3% — 53% above fast responders
Flag candidates responding in 3–6 days for same-day internal review. Measure time-from-candidate-response-to-recruiter-next-step weekly. These are your highest-intent candidates — treat them accordingly.
Expected: Improved recruiter efficiency without changing headcount
04
Set Score Thresholds Before Generating Offers
// Data: Hired avg 81.6 on all assessments — not-hired avg 72.9
Use Technical ≥ 78 and Behavior ≥ 78 as soft thresholds before advancing to offer. This directly addresses the Test → Offer bottleneck (30.5%), the steepest cliff in the entire pipeline.
Expected: Fewer wasted offers, higher per-offer conversion rate
05
Redirect Budget From Low-ROI Channels
// Data: Evento (4.9%) + Indicação (3.2%) = 145 candidates, 6 hires
The same 145 sourcing slots applied to Github or Inbound would yield an estimated 14–16 additional hires — more than double. Reduce Evento participation. Rethink Indicação: referrals need pre-screening before entering the pipeline.
Expected: 2× hires from reallocated sourcing effort
